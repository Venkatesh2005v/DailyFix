# DailyFix 🚀
**An AI-Powered Full-Stack Productivity & Insight Platform**

---

**OVERVIEW**

DailyFix is an intelligent productivity hub that transforms raw user inputs into actionable insights using the **Gemini API**. It features a robust **Spring Boot** backend and a high-performance **Next.js** frontend built with **TypeScript**.

---

**CORE FEATURES**
* 🧠 **AI Intelligence:** Real-time task analysis and summarization via Gemini API.
* 🔐 **Stateless Security:** Secure login powered by **JWT** and **Spring Security**.
* ⚡ **Performance:** Fast, SEO-friendly rendering using **Next.js**.
* 🛡️ **Type Safety:** Robust frontend architecture using **TypeScript**.
* 🎨 **Modern UI:** Responsive design built with **Tailwind CSS** and **Framer Motion**.

---

**TECH STACK**
* **Backend:** Java, Spring Boot (Data JPA, Security)
* **Frontend:** Next.js, React.js, TypeScript
* **Database:** PostgreSQL
* **AI:** Google Gemini API
* **Styling:** Tailwind CSS
